# Translate Reader

Читання англійських книжок у браузері з миттєвим перекладом українською або російською.
Клік (або тап) по слову показує переклад, а виділення фрази перекладає її цілком.

Нічого не треба встановлювати. Переклад безкоштовний, без ключів і реєстрації.

## Можливості

- **Клік / тап по слову** показує переклад і варіанти значень за частинами мови (ім., дієсл., прикм. …).
- **«Перекласти речення»**: кнопка у спливаючому віконці перекладає все речення, у якому стоїть слово.
- **Виділення фрази** мишкою або довгим натисканням на телефоні перекладає виділений текст.
- **Наведення**: необовʼязковий режим, у якому переклад з'являється, коли мишка затримується на слові (тільки на ПК).
- **УКР / РУС**: перемикач мови перекладу.
- **A− / A+**: розмір шрифту (14–32px). Вибір запамʼятовується.
- Книжковий вигляд: вузька колонка-«сторінка», шрифт із засічками. На телефоні текст займає весь екран.
- Уже перекладені слова кешуються в браузері, тому повторно сервіс не викликається.

## Як підготувати книжку

Підтримуються файли **CHM** і будь-яка **папка з HTML-сторінками** (наприклад, розпакований EPUB).

```powershell
powershell -ExecutionPolicy Bypass -File prepare-book.ps1 "C:\Books\book.chm"
```

Скрипт:
1. розпаковує CHM у HTML (вбудованим у Windows `hh.exe`);
2. копіює файли рідера в папку `reader/` книжки;
3. підключає рідер до кожної сторінки;
4. створює стартову сторінку `index.html`.

Результат зʼявиться поруч із книжкою в папці `<назва>_reader`. Іншу папку можна вказати параметром `-Out "C:\шлях"`.

## Як читати

**На комп'ютері:** відкрийте `index.html` з підготовленої папки.

**На телефоні (iPhone / Android) через Wi-Fi:**
1. На комп'ютері запустіть `phone-server.bat` з підготовленої папки (потрібен встановлений [Python](https://www.python.org/)).
2. Вікно покаже адресу на зразок `http://192.168.1.11:8000`. Відкрийте її на телефоні, підключеному до тієї самої Wi-Fi мережі.
3. Поки вікно сервера відкрите, книжка доступна. Щоб зупинити сервер, закрийте вікно.

При першому запуску Windows може запитати дозвіл у брандмауері. Його треба дозволити для **приватних** мереж.

## Як це працює

| Файл | Що робить |
|---|---|
| `reader/translate.js` | Знаходить слово під курсором, показує віконце з перекладом, панель налаштувань |
| `reader/reader.css` | Книжкова верстка і розмір шрифту |
| `reader/phone-server.bat` | Запускає локальний сервер для телефона й показує його адресу |
| `prepare-book.ps1` | Готує книжку: розпаковує й підключає рідер |

Переклад береться з безкоштовного ендпоінту Google Translate. Якщо він недоступний, рідер звертається до [MyMemory](https://mymemory.translated.net/).

## Обмеження

- Потрібен інтернет.
- Google може тимчасово обмежувати занадто часті запити. Тоді переклад іде через MyMemory, а він має денний ліміт.
- Книжки в репозиторій не додаються (див. `.gitignore`).
